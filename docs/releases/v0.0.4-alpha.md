# v0.0.4-alpha — the approval interface

**Released:** 2026-09-27
**Milestone:** M4 — the approval interface. Complete, and verified by hand.

---

## Why this release exists

The product's entire claim is one sentence:

> **Capybaras halts a destructive AI action, states plainly what it intends to do, and cannot proceed without a human.**

That claim is now tested two ways: in code, and by a person clicking.

---

## The milestone acceptance test — PASSED

Run by hand on 2026-09-27 against the July 2025 incident: an agent with delete
rights, acting during a declared code and action freeze, deleting 1,200 records.

Verbatim from the application log:

```
[5:10:42 PM] approval required: Delete 1200 records from the production database? [hard_gate]
[5:11:02 PM] answering dev-1: deny
[5:11:02 PM] resolved: dev-1 → denied
[5:11:10 PM] propose dev-2: fs.read
[5:11:10 PM] proceeded: dev-2 (silent) — Reading is free.
[5:11:17 PM] approval required: Change a file in notes.md? [confirm]
[5:11:35 PM] approval required: Delete 5000 files in the project folder? [hard_gate]
[5:11:40 PM] approval required: Send a payment? [hard_gate]
[5:11:47 PM] resolved: dev-5 → denied
```

Read that for what it is. The destructive action **halted**. It **said what it was
going to do, in words**. A read **proceeded freely** — the gate is not an obstacle
people will route around. And **nothing ran without an answer**: every denial was
honoured, and no denied action ever proceeded.

The interface was confirmed visually at the same time: live status values, all six
agents rendered, and the card.

## What is in it

**The approval interface**, end to end:

- **A protocol** (`docs/protocol.md`) between the interface and the engine —
  versioned, newline-delimited JSON, with an unsupported version **refused rather
  than guessed at**.
- **A gate** that classifies every action before it runs, in one of four tiers:
  silent, notify, confirm, hard gate. Classification is done by the system, not by
  the model, so a manipulated agent cannot argue its way to a lower tier.
- **An approval channel that cannot be bypassed** — the blocking round trip, a
  denial that is final, and answers for unknown or already-resolved actions
  refused rather than queued.
- **Durable grants** that survive a restart and **fail closed**: a corrupt grants
  file yields an *empty* store, so everything asks again. A persistence bug can
  only ever make the product more annoying, never less safe.
- **The herd** — six agents reporting real state, because quiet is information.

---

## Also in this release

- **A skill registry** — one declarative list replacing three that could disagree,
  where a skill that has not declared how it can hurt you **fails the build**.
- **The PDF family**, the first real suite: reads are silent, creation notifies,
  mutation confirms, and unlocking and attaching are hard gates. `pdf.redact`
  carries a **post-condition**, because a black rectangle over text leaves the text
  extractable and the document *looks* redacted.
- **A protection policy** — freezes and off-limits targets come from
  **configuration, not from the action**, so an agent cannot simply not declare
  one. An action can add caution; it can never remove it.
- **CI** on every push, and a UI smoke test that asserts on the rendered DOM.

## Defects found by running it, which is the point of running it

**The bridge bug.** The first hand-run failed completely: the window opened, the
layout rendered perfectly, and every button died with `invoke is not a function`.
Tauri v2 moved `invoke` under `core`; the frontend used the v1 location.

It shipped because the smoke test **mocks** the bridge — with the same wrong
assumption. The test validated a belief about the API rather than the API. The
mock now mirrors the real shape, and the test was **proven able to fail** by
temporarily reintroducing the bug.

**A preposition.** The card said *"Delete 1,200 records **to** the production
database."* Fixed to *"from"*. Small, and not cosmetic: the whole promise is that
someone who does not know what `db.delete` means can read the card, and a wrong
preposition makes it read like a machine at the moment it must read like a
deliberate decision.

## Known limits, stated rather than hidden

- **The policy file location is not yet trustworthy.** It sits in the state
  directory, which is also where writable state lives, so an agent with file access
  could tamper with it. Truly protecting it needs OS-level permissions or a home
  outside the agent's reach. Nothing is signed, and freezes have no expiry.
- **No model is wired in.** The scenario is driven by a button, deliberately: it
  removes the model as a variable so the *gate* is what is under test. M5 is the
  model connection.
- **`protectedTarget` still arrives from the caller** for ordinary actions. The
  policy closes this for freezes and declared patterns; a full answer needs the
  freeze to be operator-managed.
- **The first CI run is unverified** — a fresh runner must compile Tauri.

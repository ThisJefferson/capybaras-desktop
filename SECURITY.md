# Security Policy

**This is pre-alpha software.** There are no security guarantees, no supported versions, and no SLAs. Capybaras can act on your behalf, and it may have vulnerabilities. We are transparent about this because trust that is earned is worth more than trust that is assumed.

---

## Reporting a vulnerability

If you find a security issue, please report it privately.

**Preferred method:** GitHub Private Security Advisory

Navigate to `https://github.com/ThisJefferson/capybaras-desktop/security/advisories` and open a new advisory. This keeps the report private and gives us a structured way to track it.

**If you cannot use GitHub advisories:** contact the maintainer directly. A public issue tracker is not the place for a vulnerability report.

---

## What you can expect

- **Acknowledgment** within one week that the report has been received.
- **An honest assessment** of severity and scope. We will not inflate or minimise it.
- **A fix timeline** that is realistic for a volunteer project. Some issues will be patched in days; others may take weeks or months.
- **Credit** if you want it, unless you prefer to remain anonymous.

---

## What we cannot promise

- **Immediate fixes.** This is not a commercial product. There is no on-call rotation, no security team, no dedicated responders. The project is maintained by people with day jobs.
- **Backports.** There are no release branches or LTS versions. Fixes land on the main branch and travel forward.
- **Embargo coordination.** We will do our best to give advance notice before a disclosure, but we may not be able to coordinate tightly with downstream consumers — because there aren't any yet.

---

## Supported versions

| Version | Supported |
|---|---|
| main (pre-alpha) | Best-effort security patches |
| Any tag before 0.1.0 | No guarantees |

Once a stable release is cut, this policy will be updated with supported-version ranges.

---

## Bounties

None. This project has no budget for bug bounties. If that changes, it will be announced here.
